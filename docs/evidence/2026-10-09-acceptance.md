# 2026-10-09 实板验收摘要

## 范围

- ESP32-A1 EV Board V1.0（板载 ESP32-S31）与 ESP32-S31-Korvo-1。
- 原本地演示固件：双板应用区烧录及校验完成，其他分区的校验值保持一致。
- 用户确认中文声音钥匙触屏界面，音量显示变化，并在同步验证前点击重新上锁。
- A1 独立 POWER 供电完整；USB DEVICE 接 Korvo USB-A Host。
- 本次解锁来源为软件 PCM Goertzel，目标 1,000 Hz，配置保持 500 ms。
- 公开导出更换开放许可字体、整理构建入口，未重新编译或烧录。此处记录原本地固件的实测。

## 同步输入与输出

播放与 UART 采集在同一个 Windows Python 进程内使用 monotonic 时间线。
运行约 22 秒，播放后停止音频并关闭串口，无清理错误。

| 阶段 | 播放开始 / 相对时间 | 输入 | 观察 |
|---|---|---|---|
| 错频 | 2,047 ms | 750 Hz，2 s 纯音 | `WRONG`；解锁计数保持 1；播放前 RMS 1,260，阶段峰值 9,174；目标强度最大 9/1000 |
| 短音 | 7,031 ms | 1,000 Hz，200 ms 纯音 | 解锁计数保持 1，无解锁快照 |
| 正确钥匙 | 12,016 ms | 1,000 Hz，2 s 纯音 | 首次解锁快照在 13,250 ms，计数 1→2，保持值 500/500；强度峰值 967/1000；匹配快照 RMS 5,812 / 5,872 |
| 停止播放后 | 约 15,437 ms 起 | 无钥匙音调 | 解锁状态锁存、计数保持 2，至采集结束 |

整个窗口 `connected=1 valid=1 pending=0`，目标与 ACK 一致，PCM 测量计数增长。
CRC / 帧头 / TX 错误计数为 0 且无新增。启动历史序列缺口为 182，窗口内增量为 0。
非致命诊断标志 `0x48` 表示硬件诊断未就绪/不可用，软件 PCM 检测工作正常。

## 观察限制与待完成项

- UART 每秒一帧，未捕到 200 ms 短音可能产生的短暂匹配；该项仅证明受控播放后解锁计数不增加。
- 首次解锁快照时间不能用于精确测量物理检测延迟。固件按 512 样本块累计，默认 16 块约 512 ms。
- 正确阶段全窗口 RMS 峰值 13,800 出现在音调结束后的环境声音中，不归于钥匙音调。
- 500 Hz、2,000 Hz 目标、主动断连后的旧状态清除与完整恢复边界尚未逐项声学验收。
- A1 芯片硬件 Goertzel 的系数、输入时钟、窗口与缩放尚未标定；原始硬件读数没有参与解锁。
- 不涉及 microSD 录音、四麦算法或人声语义识别验收。

此摘要去除了设备序列号、MAC、本机路径与进程记录。原始采集日志保存在发布者本地。
